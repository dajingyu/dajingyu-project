离线存储核心技术（应试精炼版） ​

一、Web Storage 核心概念 ​

Web Storage 是什么？ ​

Web Storage 是 HTML5 提供的本地存储 API，用于在浏览器中存储数据，比 Cookie 更强大、容量更大。

两种类型 ​

  • localStorage：永久存储，除非主动删除或清除浏览器数据，否则一直存在
  • sessionStorage：会话级存储，仅在当前标签页有效，关闭标签页后数据清除

二、核心 API 使用 ​

基本操作 ​

javascript
// 存储数据
localStorage.setItem('key', 'value');
sessionStorage.setItem('key', 'value');

// 获取数据
const value = localStorage.getItem('key');
const value2 = sessionStorage.getItem('key');

// 删除指定数据
localStorage.removeItem('key');
sessionStorage.removeItem('key');

// 清空所有数据
localStorage.clear();
sessionStorage.clear();

// 获取指定索引的 key
const key = localStorage.key(0); // 获取第 0 个 key

// 获取存储数量
const length = localStorage.length;

⚠️ 重要细节：数据类型转换 ​

1. 存储时自动转换为字符串 ​

javascript
// ❌ 错误理解：存储什么类型，取出什么类型
localStorage.setItem('number', 123);
localStorage.setItem('boolean', true);
localStorage.setItem('object', { name: 'test' });

// ✅ 实际情况：取出的都是字符串
typeof localStorage.getItem('number'); // "string" → "123"
typeof localStorage.getItem('boolean'); // "string" → "true"
typeof localStorage.getItem('object'); // "string" → "[object Object]"

2. 存储对象需要序列化 ​

javascript
// ❌ 错误：对象会被转为 "[object Object]"
const user = { name: 'John', age: 30 };
localStorage.setItem('user', user);
localStorage.getItem('user'); // "[object Object]"（丢失数据）

// ✅ 正确：使用 JSON.stringify
localStorage.setItem('user', JSON.stringify(user));
const userStr = localStorage.getItem('user');
const userObj = JSON.parse(userStr); // { name: 'John', age: 30 }

3. 存储数组也需要序列化 ​

javascript
// ❌ 错误：数组会被转为字符串，但格式不对
const arr = [1, 2, 3];
localStorage.setItem('arr', arr);
localStorage.getItem('arr'); // "1,2,3"（字符串，不是数组）

// ✅ 正确：使用 JSON.stringify
localStorage.setItem('arr', JSON.stringify(arr));
const arrStr = localStorage.getItem('arr');
const arrObj = JSON.parse(arrStr); // [1, 2, 3]

4. 数字和布尔值需要手动转换 ​

javascript
// 存储数字
localStorage.setItem('count', 100);
const count = Number(localStorage.getItem('count')); // 或 parseInt()
// 或
const count = +localStorage.getItem('count'); // 一元运算符

// 存储布尔值
localStorage.setItem('isLogin', true);
const isLogin = localStorage.getItem('isLogin') === 'true'; // 字符串比较
// 或
const isLogin = JSON.parse(localStorage.getItem('isLogin')); // 如果存储时用了 JSON.stringify

封装工具函数（推荐） ​

javascript
const storage = {
  // 设置（自动处理对象）
  set(key, value) {
    const data = typeof value === 'object' ? JSON.stringify(value) : value;
    localStorage.setItem(key, data);
  },
  
  // 获取（自动解析）
  get(key) {
    const data = localStorage.getItem(key);
    if (!data) return null;
    
    // 尝试解析 JSON
    try {
      return JSON.parse(data);
    } catch {
      // 解析失败，返回原始字符串
      return data;
    }
  },
  
  // 删除
  remove(key) {
    localStorage.removeItem(key);
  },
  
  // 清空
  clear() {
    localStorage.clear();
  }
};

// 使用
storage.set('user', { name: 'John' });
const user = storage.get('user'); // { name: 'John' }

三、localStorage vs sessionStorage ​

对比表 ​

特性localStoragesessionStorage
生命周期永久存储，除非主动删除会话级，关闭标签页清除
作用域同源的所有标签页共享仅当前标签页
容量限制5-10MB（浏览器不同）5-10MB（浏览器不同）
存储位置浏览器本地文件系统浏览器内存（会话期间）
使用场景用户偏好设置、登录状态临时数据、表单草稿

实际应用 ​

javascript
// localStorage：用户偏好设置
localStorage.setItem('theme', 'dark');
localStorage.setItem('language', 'zh-CN');

// sessionStorage：表单草稿（关闭标签页后清除）
sessionStorage.setItem('formDraft', JSON.stringify(formData));

// localStorage：跨标签页通信
window.addEventListener('storage', (e) => {
  console.log('数据变化:', e.key, e.newValue);
  // 注意：当前标签页修改 localStorage 不会触发 storage 事件
  // 只有其他标签页修改才会触发
});

四、Web Storage vs Cookie ​

核心区别 ​

特性Web StorageCookie
容量5-10MB4KB
网络传输不随请求发送每次请求都发送（浪费带宽）
API原生 API（setItem/getItem）需要手动封装
作用域同源策略，不可跨域可设置 domain，可跨域
过期时间localStorage 永久，sessionStorage 会话可设置过期时间
用途本地存储数据与服务器交互（HTTP 规范）

细节说明 ​

javascript
// Cookie：需要手动设置
document.cookie = 'name=value; expires=Thu, 18 Dec 2024 12:00:00 UTC; path=/';

// Web Storage：简单直接
localStorage.setItem('name', 'value');

五、重要细节和注意事项 ​

1. 存储容量限制 ​

javascript
// ⚠️ 超出容量会抛出异常
try {
  localStorage.setItem('largeData', 'x'.repeat(10 * 1024 * 1024)); // 10MB
} catch (e) {
  if (e.name === 'QuotaExceededError') {
    console.error('存储空间不足');
  }
}

// 检测可用空间（估算）
function getStorageSize() {
  let total = 0;
  for (let key in localStorage) {
    if (localStorage.hasOwnProperty(key)) {
      total += localStorage[key].length + key.length;
    }
  }
  return total; // 字节数
}

2. 同源策略 ​

javascript
// ✅ 同源可以访问
// http://example.com/page1.html 和 http://example.com/page2.html 共享 localStorage

// ❌ 不同源无法访问
// http://example.com 和 https://example.com 是不同的源（协议不同）
// http://example.com 和 http://other.com 是不同的源（域名不同）
// http://example.com:80 和 http://example.com:8080 是不同的源（端口不同）

3. 同步操作（可能阻塞） ​

javascript
// ⚠️ localStorage 是同步操作，大量数据可能阻塞主线程
// 解决方案：使用异步封装或 Web Workers

// 异步封装示例
function setItemAsync(key, value) {
  return new Promise((resolve, reject) => {
    try {
      localStorage.setItem(key, value);
      resolve();
    } catch (e) {
      reject(e);
    }
  });
}

4. 存储事件监听 ​

javascript
// ⚠️ 重要：只有其他标签页修改 localStorage 才会触发 storage 事件
// 当前标签页修改不会触发

window.addEventListener('storage', (e) => {
  console.log('key:', e.key); // 修改的 key
  console.log('oldValue:', e.oldValue); // 旧值
  console.log('newValue:', e.newValue); // 新值
  console.log('url:', e.url); // 修改的页面 URL
});

// 当前标签页修改（不会触发 storage 事件）
localStorage.setItem('test', 'value');

// 其他标签页修改（会触发 storage 事件）

5. 隐私模式和兼容性 ​

javascript
// ⚠️ 隐私模式（Safari）下，localStorage 可能无法使用
function isStorageAvailable() {
  try {
    const test = '__storage_test__';
    localStorage.setItem(test, test);
    localStorage.removeItem(test);
    return true;
  } catch (e) {
    return false;
  }
}

if (!isStorageAvailable()) {
  console.warn('localStorage 不可用');
  // 降级方案：使用 Cookie 或内存存储
}

6. 数据类型细节总结 ​

javascript
// ✅ 存储字符串：直接存储
localStorage.setItem('str', 'hello');
localStorage.getItem('str'); // "hello"（字符串）

// ✅ 存储数字：取出是字符串，需要转换
localStorage.setItem('num', 123);
localStorage.getItem('num'); // "123"（字符串）
Number(localStorage.getItem('num')); // 123（数字）

// ✅ 存储布尔值：取出是字符串，需要转换
localStorage.setItem('bool', true);
localStorage.getItem('bool'); // "true"（字符串）
localStorage.getItem('bool') === 'true'; // true（布尔值）

// ✅ 存储 null/undefined：会被转为字符串
localStorage.setItem('null', null);
localStorage.getItem('null'); // "null"（字符串，不是 null）

localStorage.setItem('undefined', undefined);
localStorage.getItem('undefined'); // "undefined"（字符串）

// ✅ 存储对象/数组：必须序列化
localStorage.setItem('obj', JSON.stringify({ a: 1 }));
JSON.parse(localStorage.getItem('obj')); // { a: 1 }

7. 性能优化建议 ​

javascript
// ❌ 不好：频繁读写
for (let i = 0; i < 1000; i++) {
  localStorage.setItem(`key${i}`, `value${i}`);
}

// ✅ 好：批量操作
const data = {};
for (let i = 0; i < 1000; i++) {
  data[`key${i}`] = `value${i}`;
}
localStorage.setItem('batch', JSON.stringify(data));

六、Application Cache（AppCache） ​

AppCache 是什么？ ​

Application Cache（应用缓存）是 HTML5 提供的离线缓存机制，允许网页在无网络时仍能访问。

⚠️ 重要：已被废弃 ​

  • 状态：AppCache 已被 W3C 废弃，不推荐使用
  • 替代方案：使用 Service Worker + Cache API

AppCache 工作原理（了解即可） ​

html
<!-- 1. 在 HTML 中声明 manifest 文件 -->
<html manifest="cache.manifest">

<!-- 2. manifest 文件内容 -->
CACHE MANIFEST
# 版本号（修改后触发更新）
# v1.0

# 需要缓存的资源
CACHE:
/index.html
/style.css
/app.js
/image.png

# 必须在线访问的资源
NETWORK:
/api/*

# 离线时的备用页面
FALLBACK:
/ /offline.html

Service Worker（现代替代方案） ​

javascript
// service-worker.js
self.addEventListener('install', (e) => {
  e.waitUntil(
    caches.open('v1').then((cache) => {
      return cache.addAll([
        '/',
        '/index.html',
        '/style.css',
        '/app.js'
      ]);
    })
  );
});

self.addEventListener('fetch', (e) => {
  e.respondWith(
    caches.match(e.request).then((response) => {
      return response || fetch(e.request);
    })
  );
});

七、实际应用场景 ​

1. 用户偏好设置 ​

javascript
// 保存用户设置
const settings = {
  theme: 'dark',
  language: 'zh-CN',
  fontSize: 14
};
localStorage.setItem('settings', JSON.stringify(settings));

// 读取用户设置
const savedSettings = JSON.parse(localStorage.getItem('settings') || '{}');

2. 登录状态管理 ​

javascript
// 登录后保存 token
localStorage.setItem('token', 'abc123');
localStorage.setItem('userInfo', JSON.stringify({ id: 1, name: 'John' }));

// 检查登录状态
function isLoggedIn() {
  return !!localStorage.getItem('token');
}

// 登出清除
function logout() {
  localStorage.removeItem('token');
  localStorage.removeItem('userInfo');
}

3. 表单草稿保存 ​

javascript
// 保存草稿
const formData = {
  title: '文章标题',
  content: '文章内容...'
};
sessionStorage.setItem('draft', JSON.stringify(formData));

// 恢复草稿
const draft = JSON.parse(sessionStorage.getItem('draft') || '{}');
if (draft.title) {
  document.getElementById('title').value = draft.title;
}

4. 购物车数据 ​

javascript
// 添加商品
function addToCart(product) {
  const cart = JSON.parse(localStorage.getItem('cart') || '[]');
  cart.push(product);
  localStorage.setItem('cart', JSON.stringify(cart));
}

// 获取购物车
function getCart() {
  return JSON.parse(localStorage.getItem('cart') || '[]');
}

八、核心面试题 ​

1. localStorage 和 sessionStorage 的区别？ ​

  • 生命周期：localStorage 永久存储，sessionStorage 会话级存储
  • 作用域：localStorage 同源所有标签页共享，sessionStorage 仅当前标签页
  • 使用场景：localStorage 适合用户偏好、登录状态，sessionStorage 适合临时数据、表单草稿

2. Web Storage 存储的数据类型？ ​

  • 重要：存储时不管什么类型，取出的都是字符串
  • 对象/数组：必须使用 JSON.stringify() 存储，JSON.parse() 读取
  • 数字/布尔值：需要手动转换类型

3. Web Storage 和 Cookie 的区别？ ​

  • 容量：Web Storage 5-10MB，Cookie 4KB
  • 网络传输：Web Storage 不随请求发送，Cookie 每次请求都发送
  • API：Web Storage 原生 API，Cookie 需要手动封装
  • 用途：Web Storage 本地存储，Cookie 与服务器交互

4. localStorage 的容量限制？ ​

  • 大小：通常 5-10MB（浏览器不同）
  • 超出处理：会抛出 QuotaExceededError 异常
  • 检测方法：使用 try/catch 捕获异常

5. localStorage 的同源策略？ ​

  • 同源定义：协议、域名、端口都相同
  • 共享范围：同源的所有标签页共享 localStorage
  • 跨域限制：不同源无法访问

6. storage 事件什么时候触发？ ​

  • 触发条件：其他标签页修改 localStorage 时触发
  • 不触发：当前标签页修改不会触发 storage 事件
  • 用途：实现跨标签页通信

7. 如何存储对象到 localStorage？ ​

javascript
// ✅ 正确：使用 JSON.stringify
localStorage.setItem('user', JSON.stringify({ name: 'John' }));
const user = JSON.parse(localStorage.getItem('user'));

// ❌ 错误：直接存储对象
localStorage.setItem('user', { name: 'John' }); // 会转为 "[object Object]"

8. localStorage 是同步还是异步？ ​

  • 同步操作：localStorage 是同步 API，可能阻塞主线程
  • 性能影响：大量数据操作可能影响页面性能
  • 优化方案：使用异步封装或 Web Workers

9. 隐私模式下 localStorage 可用吗？ ​

  • Safari：隐私模式下 localStorage 可能无法使用
  • 检测方法：使用 try/catch 检测是否可用
  • 降级方案：使用 Cookie 或内存存储

10. Application Cache 的状态？ ​

  • 已废弃：AppCache 已被 W3C 废弃
  • 替代方案：使用 Service Worker + Cache API
  • 了解即可：面试可能问到，但不推荐使用

11. 如何实现跨标签页通信？ ​

javascript
// 方法1：storage 事件
window.addEventListener('storage', (e) => {
  console.log('数据变化:', e.key, e.newValue);
});

// 方法2：BroadcastChannel API（现代方案）
const channel = new BroadcastChannel('my-channel');
channel.postMessage({ type: 'update', data: 'value' });
channel.onmessage = (e) => {
  console.log('收到消息:', e.data);
};

12. localStorage 存储的数据会过期吗？ ​

  • localStorage：不会过期，除非主动删除或清除浏览器数据
  • sessionStorage：关闭标签页后自动清除
  • Cookie：可以设置过期时间

13. 如何安全地存储敏感数据？ ​

  • 不建议：localStorage 不适合存储敏感数据（如密码、token）
  • 原因：容易被 XSS 攻击窃取
  • 建议：敏感数据使用 HttpOnly Cookie 或服务端存储
