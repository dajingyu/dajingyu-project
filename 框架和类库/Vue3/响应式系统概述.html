Vue 3 响应式系统概述 ​

与 Vue 2 的对照见：Vue2与Vue3对比/响应式对比.md
官方文档：响应式基础、深入响应式系统

核心角色（组合理解） ​

主要由 reactive / ref（创建响应式数据）、track（依赖收集）、trigger（触发更新）、effect（副作用，通常包含更新视图的逻辑） 等概念协同工作（具体命名以运行时实现为准，面试可用这套表述串联）。

  • reactive：将对象转为响应式（内部基于 Proxy）。
  • track：在「读」数据时建立依赖关系（响应式数据 ↔ 当前 effect）。
  • trigger：在「写」数据时通知相关 effect 重新执行。
  • effect：保存如何更新（例如组件渲染函数对应的更新逻辑）。

流程简述 ​

  1. 使用 reactive / ref 时，内部通过 Proxy（或 ref 包裹） 拦截读写；get 时除返回值外会 track，set 时更新值并 trigger。
  2. 组件渲染会处于某个 effect 上下文中；渲染过程读取到的响应式字段会把当前 effect 登记为依赖。
  3. 依赖结构常用多层容器组织（例如 WeakMap → Map → Set），便于按「对象 → 属性 → 多个 effect」查找与清理。
js
// 依赖收集结构的直观示意（非源码）
{
  // WeakMap：key 为响应式对象
  { age: 18 }: {
    // Map：key 为属性名
    age: new Set([effect1, effect2 /* ... */])
  }
}
  1. 更新数据时，同步改值；随后 trigger 找到对应 effect，把视图更新调度进异步队列（与 nextTick 等机制配合），从而完成界面更新。

与组合式 API 的关系 ​

日常在 <script setup> 里写的 ref / reactive / computed / watch，底层都建立在上述响应式与 effect 调度之上；模板中 ref 自动解包等规则也由此推导。
