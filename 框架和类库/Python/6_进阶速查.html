6.2 match / case（3.10+） ​

python
match command:
    case "quit":
        break
    case ["load", path]:
        load(path)
    case {"name": name, "age": age}:
        print(name, age)
    case _:
        print("unknown")

6.3 装饰器（初识） ​

python
def log(func):
    def wrapper(*args, **kwargs):
        print("call", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log
def add(a, b):
    return a + b
  • 本质：函数接收函数，返回新函数；常用于日志、权限、缓存。

6.4 生成器 yield ​

python
def read_lines(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.rstrip()

for line in read_lines("big.log"):
    process(line)
  • 惰性求值，适合大文件、大数据流。

6.5 类型注解与 typing ​

python
from typing import Optional, List, Dict, Callable

def find_user(id: int) -> Optional[dict]:
    ...

def apply(fn: Callable[[int], int], x: int) -> int:
    return fn(x)

names: List[str] = []
scores: Dict[str, int] = {}
  • 3.9+ 可用内置泛型：list[str]、dict[str, int]。
