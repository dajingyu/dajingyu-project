1. 基础语法 ​

1.1 运行方式 ​

bash
python3 hello.py          # 运行脚本
python3 -c "print(1+1)"   # 单行
python3                   # 进入交互式 REPL，适合试语法

1.2 变量与命名 ​

  • 无需声明类型，赋值即创建变量。
  • 命名：snake_case（变量、函数）；类名 PascalCase；常量习惯全大写 MAX_SIZE。
  • 没有 const，约定用大写表示「不应改」。
python
name = "Tom"
age = 25
PI = 3.14159

1.3 基本类型（内置） ​

类型示例说明
int42任意精度整数
float3.14浮点
boolTrue, False首字母大写
str"hi", 'hi', """多行"""字符串
NoneNone空值，类似 JS 的 null
python
type(42)        # <class 'int'>
bool("")        # False
bool("hello")   # True

1.4 运算符要点 ​

python
10 / 3    # 3.333...  真除法，结果是 float
10 // 3   # 3         整除
10 % 3    # 1         取余
2 ** 10   # 1024      幂

# 比较链（Python 特色）
1 < x < 10

# 成员
"a" in "abc"
3 in [1, 2, 3]

# 同一对象（不是值相等）
a is b      # 身份比较
a == b      # 值比较

1.5 输入输出 ​

python
name = input("请输入名字: ")   # 始终返回 str
print("Hello", name, sep="-", end="!\n")

# f-string（推荐，3.6+）
score = 90
print(f"{name} 得分 {score:.1f}")

1.6 分支 ​

python
if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "B"
else:
    grade = "C"
  • 没有 switch（3.10+ 可用 match/case，见 进阶速查）。

1.7 循环 ​

python
# for：遍历可迭代对象
for i in range(5):       # 0,1,2,3,4
    print(i)

for idx, item in enumerate(["a", "b"]):
    print(idx, item)

# while
n = 3
while n > 0:
    n -= 1

# break / continue 与 JS 相同

range(start, stop, step)：左闭右开，stop 不包含。

1.8 缩进与代码块 ​

  • 用缩进表示块，通常 4 空格；混用 Tab 和空格会报错。
  • 行末冒号 : 表示后面是块：if、for、def、class 等。

1.9 注释与文档字符串 ​

python
# 单行注释

def add(a, b):
    """函数说明，可用 help(add) 或 __doc__ 查看"""
    return a + b
