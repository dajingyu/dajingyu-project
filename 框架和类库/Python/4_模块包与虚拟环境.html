4. 模块、包与虚拟环境 ​

4.1 模块是什么 ​

  • 一个 .py 文件 就是一个模块。
  • 模块里定义的变量、函数、类，可通过 import 在其他文件使用。
python
# utils.py
def add(a, b):
    return a + b

# main.py
import utils
utils.add(1, 2)

from utils import add
add(1, 2)

from utils import add as plus

4.2 包（package） ​

  • 包 = 带 __init__.py 的目录（3.3+ 命名空间包可没有，初学先按「目录 + __init__.py」理解）。
  • 导入路径对应目录结构。
myproject/
  main.py
  app/
    __init__.py
    services/
      __init__.py
      user.py
python
from app.services.user import get_user

4.3 import 规则速查 ​

写法说明
import math导入模块
from math import sqrt导入模块内名字
from math import sqrt as s别名
from package import *不推荐，污染命名空间
  • if __name__ == "__main__"：文件被直接运行时执行，被 import 时不执行（写测试入口常用）。
python
def main():
    print("run")

if __name__ == "__main__":
    main()

4.4 虚拟环境 venv ​

为什么要用：隔离项目依赖，避免全局 Python 包版本冲突（类似前端每个项目自己的 node_modules）。

bash
python3 -m venv .venv
source .venv/bin/activate
pip install requests
pip freeze > requirements.txt
pip install -r requirements.txt
deactivate

4.5 pip 常用命令 ​

命令作用
pip install 包名安装
pip install 包名==1.2.3指定版本
pip uninstall 包名卸载
pip list已安装列表
pip freeze导出依赖（生成 requirements）
pip show 包名查看包信息
  • 国内镜像（临时）：pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名

4.6 推荐项目结构（小脚本 → 小项目） ​

project/
  .venv/
  requirements.txt
  README.md
  src/
    myapp/
      __init__.py
      main.py
      utils.py
  tests/
    test_utils.py
  • 运行：python -m myapp.main（在 src 的父目录，且配置 PYTHONPATH 或安装为可编辑包）。
